# Biblioteca visual do catálogo Croma

Cada produto pode receber uma composição por camadas. A biblioteca deve preservar os arquivos originais e deixar a composição comercial para o site.

Ordem padrão:

1. fundo branco ou contextual;
2. produto/mockup recortado;
3. sombra e iluminação;
4. selos informativos renderizados pelo site.

Convenção sugerida por produto:

- produto-transparente.webp: recorte ou mockup principal;
- fundo-branco.webp: fundo limpo;
- fundo-croma.webp: fundo contextual da identidade;
- detalhe-01.webp: acabamento, escala ou uso;
- visual.json: mapa das camadas e selos.

No catálogo, a imagem limpa deve continuar disponível. Selos de preço, promoção, prazo e estoque são dados da página e não devem ser gravados na imagem principal.
