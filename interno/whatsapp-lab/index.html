O código roda somente dentro do WhatsApp Web. O painel pode ser arrastado e redimensionado, baixa texto ou um ZIP organizado e envia a conversa diretamente para este laboratório pelo ícone ✦.

  3. Execute o código copiado ou use o favorito de um clique.
